# IPTV Россия

Плейлист публично доступных российских IPTV-каналов. Собран на основе базы [iptv-org/iptv](https://github.com/iptv-org/iptv) — оставлены только каналы России.

В сборке несколько файлов:
- `streams/ru.m3u` — основной список российских каналов
- `streams/ru_*.m3u` — отдельные плейлисты от конкретных провайдеров (RT, НТВ, Смотрим и др.)

Ссылку можно сократить через [tinyurl.com](https://tinyurl.com) — так удобнее вводить на ТВ пультом.

## 🚀 Как подключить на ТВ (приложение Lampa)

1. Открой приложение **Lampa** на телевизоре.
2. Зайди в **Настройки** (иконка шестерёнки).
3. Найди раздел **Онлайн-TV** (или **IPTV** — в зависимости от версии приложения).
4. Выбери пункт **Плейлист** / **Добавить плейлист** / **M3U-плейлист**.
5. В поле для ввода ссылки вставь свою ссылку на `ru.m3u` (см. выше).
6. Нажми **Сохранить** / **ОК** и подожди, пока приложение загрузит список каналов.
7. Открой раздел **Онлайн-TV** в главном меню — там появятся российские каналы.

## 🚀 Как подключить в других плеерах

Общий принцип одинаков почти везде — нужно найти пункт добавления плейлиста по ссылке (URL):

- **VLC**: Медиа → Открыть URL адрес → вставить ссылку → Воспроизвести
- **TiviMate**: Настройки → Плейлисты → Добавить плейлист → M3U Playlist → вставить ссылку
- **IPTV Smarters**: Add Playlist → M3U URL → вставить ссылку
- **Kodi (PVR IPTV Simple Client)**: в настройках аддона указать ссылку в поле "M3U Play List URL"

## ℹ️ Об источнике

Данные о каналах взяты из репозитория [iptv-org/iptv](https://github.com/iptv-org/iptv) — открытой базы публично доступных ссылок на трансляции со всего мира. Файлы видео в этом репозитории не хранятся, только ссылки на публично доступные потоки.

## ⚖ Правовая информация

Репозиторий не хранит видеофайлы — только ссылки на публично доступные потоки. Если какая-то ссылка в плейлисте нарушает твои авторские права, обратись к хостингу, который реально раздаёт этот контент (не к GitHub и не к автору этого репозитория).
